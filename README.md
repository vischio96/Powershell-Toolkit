# PowerShell Toolkit

Raccolta di script PowerShell per amministratori di sistema Windows / Active Directory.
Ogni script vive nella propria cartella con guida (`README.md`) e registro revisioni (`CHANGELOG.md`).

| Script | Descrizione |
| --- | --- |
| [Active Directory security report](Active%20Directory%20security%20report/) | Report HTML di sicurezza e inventario di Active Directory |
| [Report permessi cartelle e condivisioni](Report%20permessi%20cartelle%20e%20condivisioni/) | Report HTML dei permessi NTFS e SMB di cartelle e share |
