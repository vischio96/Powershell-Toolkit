# Active Directory security report

Script PowerShell in sola lettura che genera un report HTML di Active Directory orientato a sicurezza e visibilità.

```powershell
.\Get-ADSecurityReport.ps1 -OpenReport
```

Requisiti: Windows PowerShell 5.1 o PowerShell 7, modulo ActiveDirectory (RSAT).
Parametri ed esempi completi: `Get-Help .\Get-ADSecurityReport.ps1 -Full`.
